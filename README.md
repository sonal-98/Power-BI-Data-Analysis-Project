# Power-BI-Data-Analysis-Project
# 📊 App Insights Unlocked: Google Play Store App Analysis – Power BI

## 📌 Project Overview

**App Insights Unlocked: A Data Analytics Challenge** is a data analysis project based on Google Play Store application data.

The objective of this project is to analyze app-related information such as **ratings, reviews, installs, size, price, categories, genres, content ratings, and update activity** to uncover meaningful patterns and trends in the Google Play Store.

The analysis focuses on understanding the factors that contribute to app performance and user preferences and translating the findings into **data-driven insights that can support app developers, product managers, marketing teams, and senior management**.

This project was completed using **Microsoft Power BI** to transform, analyze, visualize, and communicate insights from the dataset.

# 🎯 Project Objectives

The major objectives of this analysis are:

The project uses the **Google Play Store Apps dataset**.

**Google Play Store Apps Dataset**

### Main Columns

| Column         | Description                                    |
| -------------- | ---------------------------------------------- |
| App            | Name of the application                        |

# 🧹 Data Cleaning and Preparation

Before performing the analysis, the dataset was prepared for visualization and analysis.

The assignment required the following data-cleaning activities:

* Handling missing values
* Converting columns into appropriate data types
* Converting **Installs** into a numeric format
* Converting **Price** into a numeric format
* Removing duplicate records
* Standardizing text values
* Formatting **Last Updated** as a date/datetime field

These cleaning requirements are based on the provided project instructions.

### Power BI Data Preparation

The dataset was imported into **Power BI** and prepared using the data transformation capabilities available in Power BI.

The cleaned data was then used to create calculated fields, measures, visualizations, and analytical dashboards.
